# Brand Site（ジュエリーブランドサイト） [3周目]

CODEJUMP 入門編の「ブランドサイト（ジュエリー）／1カラム」課題として制作しているWebサイトです。（基礎固めの3周目）

## 概要

「知人のデザイナーが立ち上げたジュエリーブランドの紹介ページを作る」という架空の案件設定のもと、ConceptとWorkをまとめた1枚のWebページを制作しています。

CODEJUMPの課題を通して、Google Fonts（Crimson Text）の導入、`vw` を用いた特徴的なコンテンツ幅の設計、ページ内リンクおよびメールリンクの設定、レスポンシブ時の並び順変更について学習しています。

## コーディング仕様・学習内容

- **フォント**: Google Fonts の `Crimson Text` を使用
- **コンテンツ幅**:
  - メインビジュアルとヘッダーメニュー: `90vw`
  - コンテンツ部分: `1000px`
  - メインビジュアルの高さ: 可変
- **グローバルナビゲーション**:
  - Concept / Work: 各コンテンツへジャンプするページ内リンク
  - Contact: メールリンク（`mailto`）の設定
- **Concept・Work セクション**:
  - 画面幅縮小時に画像とテキストエリアが縮小する設計
- **フッター**:
  - ロゴとコピーライトを横並びで両端に配置
- **レスポンシブ対応**:
  - ブレークポイント 767px
  - スマホ時は画像とテキストを縦並びに配置（Workは「画像、テキスト」の順に並ぶようCSSで制御）
- **Git / GitHub**: バージョン管理
